# Product overview

**kiro-computer-vision** is a workshop repository for Kiroverse Week 7: Build Nights.

## Purpose

Participants fork this repo, make a folder in `projects/<their-username>/`, and use
Kiro to build a computer vision application. Everything else — the demo suite, the
prompt library, the starter app — is reference material to borrow from.

## Target users

- Workshop participants building a CV app during Build Night
- Developers who want a clean starting point for OpenCV + MediaPipe pipelines
- Anyone learning to prompt an AI coding assistant for vision code

## What participants do

1. Fork and clone
2. Create `projects/<username>/`
3. Set up the venv (Python 3.10–3.12, `pip install -r requirements.txt`)
4. Open `docs/prompts/`, pick a prompt, and start building with `kiro-cli chat`
5. Present what they built at showcase

## What is NOT the goal

- Training or fine-tuning models
- Building a production deployment
- Modifying the demos themselves (they are reference, not the product)
- Cloud deployment or distributed inference

## Key principle

Participants build in `projects/`. The demos stay untouched as examples. When
helping a participant, work inside their folder, not in `demos/` or the shared docs.
